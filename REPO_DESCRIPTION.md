# 项目名称: deepseek-cost-watcher

## GitHub 描述 (350字)

开源的多账户 DeepSeek API 消费监控面板。实时追踪账户余额变化与消费趋势，支持日/周消费报告、模型用量分布、API 调用明细查询。内置请求代理层，自动记录每次调用的 Token 消耗与费用，支持多 API Key 管理与 AES-256-GCM 加密存储。基于 Vue 3 + FastAPI + SQLite 构建，Docker Compose 一键部署，无需外部依赖。

## Description (English, ~300 chars)

Open-source multi-account DeepSeek API cost monitoring dashboard. Track balance changes and consumption trends in real-time, with daily/weekly cost reports, model usage distribution, and API call history. Built-in proxy layer auto-records token usage and costs per call, supports multiple API keys with AES-256-GCM encryption. Built with Vue 3 + FastAPI + SQLite, one-click deploy via Docker Compose with zero external dependencies.
